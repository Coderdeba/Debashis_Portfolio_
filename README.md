# Debashis Barmon — Portfolio

A responsive, single-page professional portfolio built with HTML, custom CSS, Tailwind CSS CDN utilities/configuration, and vanilla JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. Keep the `assets` folder beside the HTML file so the profile photo loads.

## Customize
- Contact details and content: `index.html`
- Colors, layout and responsive styles: `styles.css`
- Mobile navigation and footer year: `script.js`
- Profile photo: `assets/profile.jpg`

Tailwind CSS is loaded from its CDN, so an internet connection is needed for Tailwind utilities. The custom stylesheet is local.
